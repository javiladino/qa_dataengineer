# 🧠 Banco de Preguntas y Respuestas — Data Engineer

Recopilación colaborativa de preguntas reales de entrevistas para **Data Engineer**, con respuestas explicadas, ejemplos de código y preguntas de seguimiento.

> ⚠️ Las empresas se mencionan de forma **anonimizada** (sector + año) para respetar la confidencialidad de los procesos de selección.

## 📚 Índice por tema

| Tema | Descripción |
|---|---|
| [SQL](preguntas/sql/) | Consultas, window functions, joins, optimización |
| [Python](preguntas/python/) | Lenguaje, estructuras de datos, pandas, testing |
| [Spark](preguntas/spark/) | PySpark, particiones, shuffles, optimización |
| [Modelado de datos](preguntas/modelado-datos/) | Kimball, star schema, SCD, Data Vault |
| [Orquestación](preguntas/orquestacion/) | Airflow, Dagster, Prefect, dbt |
| [Cloud](preguntas/cloud/) | AWS, GCP, Azure, data warehouses |
| [Streaming](preguntas/streaming/) | Kafka, Flink, Spark Streaming, CDC |
| [System Design](preguntas/system-design/) | Diseño de pipelines y arquitecturas de datos |
| [Behavioral](preguntas/behavioral/) | Preguntas de comportamiento (método STAR) |

## 🏷️ Niveles

- 🟢 **Junior** — conceptos fundamentales
- 🟡 **Mid** — aplicación práctica y trade-offs
- 🔴 **Senior** — diseño, escalabilidad y liderazgo técnico

## 🤝 Cómo contribuir

¿Te hicieron una pregunta interesante en una entrevista? ¡Compártela!

- **Tienes la pregunta pero no la respuesta:** abre un [Issue](../../issues/new/choose) con la plantilla *Nueva pregunta*.
- **Tienes pregunta y respuesta:** abre un Pull Request usando la [plantilla](templates/pregunta.md).

Lee la [guía de contribución](CONTRIBUTING.md) antes de empezar.
